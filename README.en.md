# English Learning Website: Learning Western Festivals Through Stories

An English learning website for fifth-grade elementary students in Taiwan. Students learn English through stories about four Western festivals and get to know the culture behind each one along the way.

- Live site: https://learn-english-western-festival.netlify.app/homepage
- Author: Yung-Fen Liu (U10809003, English Teaching, Year 5)

## Content

The site covers four festivals: Easter, Halloween, Thanksgiving, and Christmas. Each festival has five sections:

| Section | Content |
| --- | --- |
| Story | An English story with narration audio, playable at 1x, 0.75x, or 0.5x speed. Students can look up new words or view a full Chinese translation |
| Practice | <!-- TODO: Describe the practice format (only the Christmas page currently uses the word cards in cards/) --> |
| Game | A memory card game where students match each English word with its Chinese meaning or picture |
| Test | Multiple-choice, true/false, and picture questions, with the score shown right after submitting |
| Extended Learning | Embedded YouTube videos that go further into each festival |

## How to Use

1. On the home page, enter your class, seat number, and name, then click "Next"
2. Pick a festival on the left, then pick a section
3. Click "Learning Record" to see how much time you spent on each section

Student information and learning records are stored only in the student's own browser (localStorage) and are never uploaded to a server. Switching devices or clearing browser data erases them.

## Tech

Plain HTML, CSS, and JavaScript with Bootstrap and jQuery, and no backend. The site is deployed on Netlify.
